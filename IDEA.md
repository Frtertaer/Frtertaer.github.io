Человек только что купил вещь и боится не успеть сдать. Кидает фото чека, выбирает магазин. Страница показывает последний день возврата и даёт файл .ics. Бесплатно видна дата. €2 — файл напоминания и чек с этой датой на полях. Аккаунта нет.
Почему это продаётся без разговоров:

Запрос уже есть: «до какого числа можно сдать в IKEA», «срок возврата Amazon». Страница под один магазин ловит этот поиск.
Боль кончается через 14–30 дней, не через два года. Гарантийные приложения напоминают слишком поздно для возврата.
Платят за файл, не за подписку и не за разговор. Касса на той же странице.
Вторая сторона не нужна. Чек уже у него в телефоне.

Первая версия — не каталог магазинов мира. Двадцать магазинов, у которых срок возврата написан правилом: 14, 30, 90 дней, праздничное исключение. Фото чека нужно только чтобы вытащить дату покупки. Если дата не читается, человек вбивает её сам, и страница всё равно считает дедлайн.
Не делай из этого кошелёк чеков. Как только начнётся «храни все покупки», ты станешь ещё одним WarrantyVault. Продукт кончается в день, когда возврат уже невозможен.
Проверка тоже кодом. Выложи пять страниц под пять магазинов, посмотри Search Console: есть ли показы по «срок возврата». Нет показов — идею не купят, сколько ни полируй сканер. Есть показы и ноль оплат — дата бесплатно закрывает боль, и продавать нечего.
